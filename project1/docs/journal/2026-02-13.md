# Development Journal - 2026-02-13

## Bug Fix: Batch LLM Scoring JSON Parsing + Fallback Chain

### Issues Addressed

**1. HTML Link Visibility in Digest Output** (cosmetic)

The paper title line in the digest used `[HTML](url)` as a markdown link, rendering as "HTML" — which blended visually with the paper title.

**Fix**: Changed to `[[HTML]](url)` in `formatter.py:26` so the rendered text shows `[HTML]` with visible brackets, clearly distinguishing the link from the title.

**2. Batch LLM Scoring Failing with JSON Parse Errors** (functional)

Error: `"Expecting ',' delimiter: line 34 column 6 (char 2513)"` on most batches, triggering fallback to individual scoring.

**Root cause**: The JSON extraction regex in `score_papers_batch_llm()` used a greedy pattern:
```python
re.search(r'\[.*\]', content, re.DOTALL)
```
This matched from the first `[` to the **last** `]` in the entire LLM response, including brackets inside string values (e.g., `"reasoning": "This paper [ref] discusses..."`), producing invalid JSON.

**Fix**: Replaced with a two-strategy extraction:
1. First try extracting from markdown code blocks (`` ```json [...] ``` ``)
2. Fall back to bracket-counting parser that tracks string boundaries and escape sequences, correctly finding the matching `]` for the outermost `[`

**3. Batch Fallback Chain Was Too Shallow** (enhancement)

Previously, when batch scoring failed, it immediately fell back to individual scoring with the same `FallbackLLMClient`. The problem: `FallbackLLMClient` only retries providers when the API *call* fails — not when the response is unparseable JSON. So an LLM returning an empty response (API success, content failure) would not trigger provider-level fallback.

**Fix**: Implemented a 3-level fallback chain:
1. **Batch per-provider**: Extract individual clients from `FallbackLLMClient` and try each provider for the batch. If any returns parseable JSON, use it.
2. **Individual scoring**: If all providers fail batch mode, score each paper individually (using the full `FallbackLLMClient` which retries providers per-call).
3. **Local scorer**: If individual scoring also fails (all providers down), use the embedding-based local score via `local_score_to_llm_scale()`.

### Debugging Detour: `str.format()` vs JSON Braces

The batch prompt template (`match_preprint_batch.md`) contains a JSON example with double braces `{{` and `}}`. Initial investigation incorrectly identified these as the bug source and "fixed" them to single braces. This broke `str.format()` — Python interpreted `{"arxiv_id"...}` as a format placeholder, raising `KeyError('\n    "arxiv_id"')`.

The double braces were **correct** — they are `str.format()` escape syntax that renders to single braces in the final prompt. This lesson was already documented (lessons.md #3) but was overlooked during initial diagnosis.
