# Development Journal - 2026-02-09

## Bug Fix Session: 4 Pipeline Bugs

Branch: `fix/project1-bugs`

### Bug 1: Primary LLM (Kimi) Skipped
**File:** `src/llm_client.py:329`
**Cause:** `create_fallback_client()` used `config.llm_fallback` directly, which didn't include the primary provider `kimi`. Moonshot succeeded first.
**Fix:** Prepend primary provider to fallback chain.

### Bug 2: Date Boundary Uses Local Time
**Files:** `src/arxiv_fetcher.py`, `src/main.py`
**Cause:** `datetime.now()` (local time) with double `+1` buffers caused 2 extra days of lookback.
**Fix:** Added `since_date` parameter to `fetch_papers()`. Update mode passes the last digest date directly — no days conversion, no buffers. Comparison uses arXiv UTC timestamps on both sides.

### Bug 3: Missing/Truncated Abstracts in --no-summary Mode
**File:** `src/formatter.py`
**Cause:** Most relevant showed "*Summary not available.*"; somewhat relevant truncated to 400 chars.
**Fix:** Both tiers now use `paper.abstract` as fallback.

### Bug 4: Cross-Listed Papers Creating Noise
**File:** `src/arxiv_fetcher.py`
**Cause:** arXiv API returns papers cross-listed in queried categories regardless of primary category. Papers from `hep-ph`, `gr-qc`, etc. polluted results.
**Fix:** Added `paper.primary_category not in category_set` filter in `fetch_papers()`. Only papers whose primary category is in the configured set are kept.
**Impact:** 19 papers → 9 papers with `--days 3` (10 cross-listings removed).
