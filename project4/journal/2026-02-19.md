## Key Decisions Captured

1. Project split:
   - `project4/` is planning/governance home
   - `project4/lamian/` is implementation home
2. Language baseline:
   - Rust selected for CLI-first and cross-platform capability
3. Storage model:
   - SQLite canonical metadata store
   - sidecar export for portability
4. Ingestion policy:
   - strict provenance required
5. MVP boundaries:
   - include vault core, metadata, tags, links, search, CLI, basic GUI
   - exclude arXiv/publication automation and built-in AI for initial release
